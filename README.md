# ELORA — Wear Confidence.

Static e-commerce website prototype.

## Run
Open `index.html` in a browser.

## Included
- Cinematic ELORA homepage
- Responsive mobile/desktop layout
- Collection lookbook
- Six products with current demo prices
- Add-to-bag interaction with localStorage
- Bag drawer and total
- Newsletter form interaction
- Story, category, shipping/returns placeholders

## Before selling
Replace the shared lookbook image with individual product images, add exact product details/sizes/stock, connect a real checkout/payment provider, configure shipping/taxes/returns, add your domain, privacy/terms pages, and test orders on mobile.
